# 제작자 표시 기준

사용자 확인: GitHub를 찾아온 사람이 ben020410 계정과 제작 이력을 보는 것은 괜찮다. 서비스 화면·홍보물에서 실명이나 개인 이메일을 대놓고 드러내지 않는 것이 목적이다.

- 서비스 제작자 표기는 3NU 중심으로 한다.
- 원래 Git 이력·저작자 이력은 삭제하거나 재작성하지 않는다.
- GitHub 준비 사본은 새 저장소로 초기화하되 원본 전체 이력은 로컬 bundle에 보관한다.
- 서비스 URL·GitHub 계정명은 은폐 대상이 아니다. 도메인 변경은 후속 단계다.
- 공개 자료에 불필요한 개인 홈 디렉터리 경로는 넣지 않는다. 준비 사본에서는 $PROJECT_ROOT, $USER_HOME으로 치환했다.
- OSM 기여자, 라이브러리 저작자, 실제 건물·기관 이름은 제작자 익명화를 이유로 제거하지 않는다.
- 참고 화면 속 플레이어 닉네임과 개인 경로가 남은 검토용 캡처는 공개용 이미지와 분리한다.

현재 production 사이트의 시각·메타데이터를 이 단계에서 일괄 변경하지 않았다. 이번 작업은 업로드 사본과 공개 표기 기준의 정리다.
