# 로컬 방명록·방문 통계 · BUILD107

공개 배포 없이 기존 캠퍼스와 멀티플레이어 서버에 SQLite 저장소·관리자 API를 연결했다. 정문 포장 가장자리의 방명록에 가까이 가서 F를 누른다. 타이틀 게시판의 공지·피드백과 별도 기능이다. 피드백 전송은 아직 연결하지 않았다.

## 실행

Node.js **24 이상**을 사용한다. 기존 npm 의존성은 ws 8.23.0이며 SQLite는 Node 내장 모듈이다.

```sh
npm ci --ignore-scripts
npm run setup:local   # 최초 한 번만. 이미 설정되어 있으면 생략
npm start
```

기본 게임: `http://127.0.0.1:8766/` · 관리자: `http://127.0.0.1:8766/admin107.html`.
현재 Mac에서 Node가 PATH에 없으면 `/Applications/ChatGPT.app/Contents/Resources/cua_node/bin/node server/local107.cjs`로 실행한다. 종료 Ctrl+C. `PORT`로 포트를 바꿀 수 있고 항상 127.0.0.1에 바인딩한다. 정적 Python 서버만 실행하면 혼자 탐방은 가능하지만 방명록·통계·멀티플레이어는 연결되지 않는다. 방명록에 연결 실패를 표시하고 저장 성공으로 처리하지 않는다.

## 비공개 저장소와 관리자

기본 위치는 프로젝트 루트의 `05-management/local-runtime/development/`다. `CAMPUS_DATA_DIR`로 다른 **main 밖**의 비공개 경로를 지정할 수 있다. 이 폴더를 Git·dist·공유 보고서에 넣지 않는다.

- `community.sqlite`와 SQLite WAL/SHM: 글, 작성자 권한 해시, 제한 이력, 신고, 방문 기록.
- `private.json`: 관리자 비밀번호 scrypt 해시·salt와 서버 비밀키. 폴더 0700, 비밀 파일 0600.
- `ADMIN-PASSWORD.txt`: 초기 생성한 임의 비밀번호를 사용자만 읽는 파일. 값은 콘솔/보고서/클라이언트에 출력하지 않는다. 관리자 로그인 창에 직접 입력한다. 보관이 끝나면 별도 비밀번호 관리 도구에 옮길 수 있다.

설정 명령은 기존 파일을 덮어쓰지 않는다. 관리자 세션은 HttpOnly/SameSite=Strict 쿠키, 8시간 만료, 서버 재시작 때 로그아웃된다. 모든 관리자 조회·CSV·수정 API에서 인증한다. 변경 요청은 같은 Origin과 JSON·CSRF 토큰을 검사한다. 로컬 HTTP에는 Secure 쿠키를 붙일 수 없으므로 현재 사용 범위는 로컬이다. 외부 운영은 TLS·프록시·신뢰 Host 설정과 별도 운영 검토가 필요하다.

관리자의 ‘이 브라우저 통계 제외’는 인증 후 서버가 서명한 별도 쿠키를 발급한다. 다음 방문 이벤트에 현재/과거 해당 브라우저 세션도 제외한다. 새 브라우저나 쿠키 삭제 후에는 다시 지정한다. 로그인만으로 자동 제외했다고 가정하지 않는다.

## 작성 권한·도배 방지

닉네임과 캐릭터는 글 작성 당시의 표시용 정보다. 작성 권한은 256비트 무작위 HttpOnly 쿠키와 DB의 SHA-256 해시로 검증한다. 방문 식별값·멀티플레이어 ID·닉네임과 분리된다. 같은 브라우저의 탭은 공유하고, 쿠키를 지우면 직접 수정 권한을 잃는다. 해당 글의 신고 → 삭제 요청으로 관리자 확인을 요청한다. 닉네임만으로 소유권을 복구하지 않는다.

- 작성자별 새 글 60초 간격, 최근 24시간 5개, Unicode NFKC/공백 정규화 후 같은 내용 재등록 금지.
- 원문/수정문 지문, 작성 제한, 요청 idempotency 키는 24시간 유지한다. 글 삭제·서버 재시작으로 제한을 초기화하지 않는다. 같은 키·내용 재시도는 원래 등록 결과를 반환한다.
- 편집 10회/분, 삭제 10회/분, 서로 다른 글 신고 10회/시간. 동일 작성자·글 조합 신고는 한 번만 기록한다. 신고 수만으로 자동 숨김/삭제하지 않는다.
- 같은 네트워크 전체의 새 글 60개/시간, 자격 발급 60회/시간, 로그인 10회/15분, 요청 1200회/분, 실패 100회/분의 보조 제한. 학교 NAT 사용자를 한 사람으로 취급하지 않으며 작성자 제한이 주 기준이다.
- 원 IP 대신 소켓 주소를 일별 HMAC으로 처리한 단기 네트워크 키만 제한 테이블에 저장한다. X-Forwarded-For는 신뢰하지 않는다. 상세 이동 경로나 IP를 통계에 저장하지 않는다.
- 빈 글·300자 초과·외부 링크를 서버에서 거절한다. 글은 plain text/textContent로 표시한다. 429는 Retry-After 및 재시도 시점을 반환하고 UI에서 초안과 남은 시간을 유지한다.
- 오래된 제한·요청 이력은 요청 시 최대 1분 간격으로 정리한다. 삭제된 글 본문/닉네임은 비우되 내부 ID·작성자 해시·관리 상태는 남긴다.

쿠키를 바꾸는 공격, 분산 네트워크, 브라우저 자동화 전체를 차단한다고 주장하지 않는다. 공개 운영 시 지속 공격에 대한 서버 검증형 bot challenge와 운영 정책을 추가 검토해야 한다. Turnstile 등 외부 서비스나 가짜 통과 화면은 추가하지 않았다.

## 통계 정의

브라우저 무작위 식별값을 해시해서 저장한다. **고유 브라우저 추정치이며 실제 사람 수가 아니다.**

- 방문: 보이는 타이틀/탐험 활동에서 시작하며 30분 비활동 후 새 세션. 새로고침·재접속·다중 탭은 같은 기간 세션으로 합친다.
- 탐험 시작: 세션 중 실제 게임에 들어간 경우 한 번. 타이틀 방문만 한 세션과 구분한다.
- 현재 탐험 중: 보이는 게임 탭의 최근 25초 heartbeat, 브라우저별 중복 제거. 숨김·종료 이벤트는 즉시 정리하며 갑작스러운 종료는 최대 25초 후 만료한다.
- 활성 시간: 보이는 게임 탭들의 시간 합집합. 여러 탭을 더하지 않는다. heartbeat 15초, 비정상 종료 시 마지막 신호 이후 최대 25초 꼬리 오차가 있다. 숨긴 탭의 주기 heartbeat는 보내지 않는다.
- 평균 활성 탐험: 탐험을 시작한 방문들의 활성 시간 평균. 타이틀만 본 세션은 평균 분모에서 제외한다.
- 재방문 브라우저: 해당 방문 시작 전에 방문 이력이 존재하는 식별값. 단순 새로고침은 재방문으로 늘리지 않는다.
- 날짜/기간: KST 방문 시작일로 분류. 자정을 넘는 세션은 시작일에 귀속한다. 기간 고유 수는 DISTINCT로 계산하며 일별 고유 수를 더하지 않는다. 오늘/최근 7일 및 누적 방문 제공.
- 개발과 검증은 DB 경로/환경을 분리한다. HeadlessChrome 등 알려진 자동화 UA는 서버에서 제외하지만 모든 자동화를 식별하는 장치는 아니다. API 검증은 별도 테스트 시계를 주입하며 제품 시계를 조작하는 URL은 없다.

CSV는 관리자 인증이 필요한 집계만 포함한다. 글 원문, 방문/작성자 ID, 쿠키, IP, 서버 비밀은 내보내지 않는다. 셀 선두 수식 문자를 무해화한다. 방문 세션/집계는 현재 보존 기간 제한 없이 로컬에 유지하고, 추후 공개 운영의 개인정보 보존 정책은 별도로 정해야 한다.

## 백업·복구

DB를 복사하는 동안의 WAL 누락을 피하도록 Node SQLite backup API를 사용한다. 서버를 켠 채 백업할 수 있으며, DB와 private.json/초기 자격 파일을 **비공개 백업**으로 함께 보관한다.

```sh
node scripts/backup-community107.cjs backup /절대경로/05-management/local-runtime/development /절대경로/04-backups/community-새날짜
node scripts/backup-community107.cjs restore /절대경로/04-backups/community-새날짜 /절대경로/05-management/local-runtime/restored-새날짜
CAMPUS_DATA_DIR=/절대경로/05-management/local-runtime/restored-새날짜 npm start
```

대상 폴더가 이미 있으면 거절한다. 사용 중인 DB를 덮어쓰지 않는다. 복구본 integrity_check 후 별도 포트에서 확인하고, 기존 데이터와 권한/제한 기록이 남는지 확인한다. 현재 스키마 user_version=1이며 더 높은 스키마는 자동 다운그레이드하지 않는다. 소스와 같은 컴퓨터의 백업은 디스크 고장·분실 대비 별도 장치 백업을 대신하지 않는다.

검증: `npm test`. 실제 로컬 화면·검증 결과는 `../../../03-history/build-reports/BUILD107/REPORT.html`. 실제 모바일·외부 네트워크 운영·장기 부하 검증은 별도다.
