# 3NU 자료 보관 기준

2026-11-15 · BUILD91 기준. 이번 단계에서는 기존 자료를 삭제하거나 이동하지 않는다.

| 구분 | 현재 위치 | 처리 |
|---|---|---|
| 실행 코드·현재 모델·라이선스 | campus-walk/dist | 유지. 배포와 재현에 필요 |
| 생성·검증 스크립트 | campus-walk/scripts | 유지. 참조 입력을 함께 추적 |
| 원본·출처 기록 | campus-walk/sources, data-sources | 비공개 보관. 재배포 권한을 사진 참고 권한과 혼동하지 않음 |
| 승인 시안·원본 이미지·최종 ZIP | design-reviews, generated_images | 유지. 최종본만 남길지 정식 배포 전에 검토 |
| 작업 인계·승인·배포 증빙 | outputs, reports/build*/deployment.json | 버전별로 유지 |
| 반복 캡처·성능 원시 로그·중간 시안 | reports, work 일부 | 정식 배포 전 일괄 검토·압축 가능. 지금은 삭제하지 않음 |
| 과거 전체 작업 복사본 | work | 현행 빌드 참조 여부 및 유일한 원본 여부를 확인한 뒤 보관/삭제 결정 |
| Sites 배포 압축본 | Documents/Codex 아래 빌드별 tar.gz | 최신 정상 빌드와 이전 정상 빌드, 정식 릴리스 기준점은 유지 |

정리 시 최소 보존 단위: 소스 커밋, 배포 버전·ID, 배포 압축본, 승인 시안, 출처·라이선스, 중요한 전후 화면, 핵심 검증 결과, 미해결 문제.

후보 파일은 이름만으로 자동 삭제하지 않는다. 컴파일 스크립트가 reports의 JSON을 입력으로 사용하는 경우가 있으므로 보고서 폴더 전체를 지우지 않는다.

개발 중 모든 빌드마다 3NU 전체 폴더를 복사하지 않는다. Git 변경 이력과 배포 증빙을 남기고, 큰 기준점에서만 전체 백업을 만든다. 백업은 GitHub 공개 저장소에 넣지 않는다.
