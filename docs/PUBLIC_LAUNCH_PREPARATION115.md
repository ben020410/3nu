## 공개 최종 단계

소유자가 지금 공개하라고 지시한 뒤에만 서버 root에서 실행:

```sh
python3 /usr/local/lib/3nu-ops/activate-public.py --publish 115
```

검토 빌드·비공개 상태·인증서 유효기간·갱신 타이머·백업 확인 → production.env로 실제 앱 전환 → Nginx/HTTPS 내부 확인 → 마지막에443 개방. 실패 시 방화벽과 서비스 설정을 비공개로 복귀하며 실제 DB는 되돌리지 않음. 전환 스크립트는 문법 검증만 완료했고 실제 공개 전환 실행은 안 함. 공개 후 외부 네트워크에서 https://165.22.247.213/ready 및 게임·방명록·멀티플레이를 확인해야 완료.

한 명령 업데이트는 기존 scripts/private-ops/update-private-server.sh 유지. 현재 공개/비공개 모드를 보존하며 이 명령 자체는 게임을 새로 공개하지 않음.
