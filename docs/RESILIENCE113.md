# BUILD113 · 연결 실패와 초안 복구 (로컬 검증)

BUILD112 고정 운영 묶음을 변경하지 않는다. 이 문서는 다음 교체 후보의 구현 기록이며 서버 설치나 공개 배포 완료 기록이 아니다.

## 연결

`multiplayer106.js`는 connecting / solo / full / restored / connected 상태를 구분한다. 자동 재접속은 기존 지수 지연을 사용하며, 수동 재연결도 같은 소켓 소유권과 연결 중 가드를 거친다. handshake 대기는 10초로 제한한다. 끊김 시 기존 공유 좌석·버스 reconcile 정책을 유지하고 실제 착석/탑승 상태가 있었다면 이유를 안내한다. 복구 안내는 6초 후 간단한 접속 인원 안내로 바뀐다. 모바일에서도 표시하며 조이스틱과 액션 버튼 사이/위에 배치한다.

## 브라우저 초안

`drafts113.js`: 같은 origin의 검증된 서버 environment별 저장소, `guest:new`, `guest:edit:<postID>`, `feedback:new`로 분리. 최대 24개, 초안 생성/수정 후 24시간. 만료 데이터는 다음 접근 때 폐기한다. 브라우저가 닫혀 있는 동안 삭제 작업을 실행할 수는 없다. 본문은 암호화하지 않은 localStorage에 저장하므로 UI에 공용 기기 삭제 안내를 표시한다. 영구 보관이나 백업 기능이 아니다.

전송 직전 요청 key·본문·pending을 함께 저장한다. 응답 유실이나 5xx는 저장 실패로 단정하지 않고 입력을 잠근 뒤 같은 key로 저장 확인한다. 성공 또는 명시적인 초안 삭제 때만 제거한다(별도 만료 정책 제외). 4xx 등 확인된 실패는 수정 가능하다. 게시글 수정도 기존 requests 테이블에서 owner+key 재실행을 막는다. 별도 스키마 변경은 없다. 새 게시글의 재시도는 key+본문으로 확인해 재방문 닉네임이 달라져도 이미 저장한 작성자를 바꾸지 않는다. BUILD112 이전 key는 기존 전체 payload 검증을 호환한다.

초안에는 닉네임·쿠키·CSRF·인증값을 저장하지 않는다. 실제 전송 시 현재 메모리 닉네임을 사용한다. 초안은 계정/작성권의 증명이 아니며 서버가 소유자 쿠키를 검증한다. 저장 실패 시 메모리로만 보존하고 새로고침 전 복사를 안내한다. 환경이 바뀐 폼은 자동 전송하지 않는다.

## 닉네임

`player-state.js`는 기존 프로필의 nickname만 제거하고 id, character와 기타 저장 필드를 유지한다. 새로고침과 타이틀 복귀 때 입력창은 비운다. 탐험 중 닉네임은 메모리에서 사용한다. start form/input autocomplete=off를 적용하지만 브라우저 자체 과거 자동완성 데이터의 삭제를 보장하지 않는다. 기존 게시글 작성자명이나 방명록 소유자 쿠키는 변경하지 않는다.

## 초기 로딩

핵심 데이터 요청 30초 제한, 준비 단계가 멈추면 45초, 전체 준비 120초 제한. 커뮤니티 JSON API는 응답 본문까지 10초 제한. 공지 재시도와 초기 화면 새로고침 버튼 제공. 초기 재시도는 전체 페이지 새로고침으로 장면/이벤트 중복을 방지한다. 온라인 API 실패만으로 3D 탐험을 차단하지 않는다.

HTML 자체를 받지 못한 경우 클라이언트 UI로 복구할 수 없다. `server/deploy/unavailable113.html`과 nginx 예시의 정확한 / 및 /index.html location은 502/504를 별도 503 안내문으로 전환하는 선택적 서버 템플릿이다. nginx가 먼저 이 파일을 제공할 수 있도록 `/srv/3nu/fallback/unavailable113.html`에 설치해야 한다. API와 /ready는 가로채지 않는다. 이 서버 구성은 로컬 Mac에서 실제 nginx로 검증하지 않았고 원격에 적용하지 않았다.

## 검증 및 경계

격리된 SQLite DB, Chrome headless 프로필 및 모바일 에뮬레이션을 사용한다. 실제 8766 서버·개인 저장소·원격 서버는 변경하지 않는다. BUILD113 보고서와 재현 스크립트는 프로젝트 03-history 아래에 둔다. 실제 휴대폰, Safari, 원격 프록시/공유망 지연과 버스 탑승 상태의 실제 네트워크 단절은 미확인으로 남긴다. BUILD112의 300명 부하 결과를 이번 빌드에서 다시 측정했다고 표현하지 않는다.
