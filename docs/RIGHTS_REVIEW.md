공개 credits.html은 BUILD11 중심 과거 구현 설명과 여러 후속 이력이 섞여 있다. 기록 보존용으로 유지하되 정식 출처 화면을 만들 때 현재 데이터·자산 출처와 과거 빌드 설명을 분리한다. 이후 타이틀/출처 화면 작업의 입력으로 사용한다.

GitHub 공개용 LICENSE를 임의로 MIT 등으로 지정하지 않는다. 권리 조건이 다른 데이터·라이브러리·공식 상징 자산을 단일 앱 라이선스로 덮지 않는다.


## 공개 전 재확인 · 2026-11-16

현재 `dist/landmark44.js`는 `assets/official-sha-symbol44.png`를, `dist/logo30136.js`는 `assets/snu-engineering-ui-original.png`를 실제로 불러온다. 두 원본은 현재 Git HEAD에도 포함돼 있다. 저장소를 공개하면 렌더 결과뿐 아니라 원본도 열람할 수 있다는 점을 구분한다.

[서울대 UI 사용 원칙](https://identity.snu.ac.kr/ui/1)은 정장의 상표권 등록, 상업적 사용 제한, 동문·외부인의 허가 경로, 고해상도 자료의 교육·행정 목적 제공 조건을 명시한다. 파일 다운로드가 가능하다는 사실만으로 이 프로젝트 및 GitHub 원본 공개 범위의 허가가 확인되지는 않는다. 이 프로젝트의 구체적인 사용 조건이나 허가 증빙은 아직 확인하지 못했다. 사용자 신분만으로 허가 유무를 단정하지 않으며, 기존 승인 외형을 임의 삭제·변경하지 않는다.

[SMASH-SNU 라이선스](https://github.com/Hong-Iron/SMASH-SNU/blob/main/LICENSE)의 코드·그림·화면 디자인 재게시 제한과 OSM 건물·도로 데이터에 대한 별도 ODbL 적용은 현재도 확인된다. 원본 라이선스 사본은 유지한다. 기존 credits의 독립 구현 설명은 제작 기록이며, 전 코드 유사성 감사를 새로 완료했다는 의미가 아니다.

고양이·플레이어·3NU 마크의 제작 기록과 외부 캐릭터/상징과의 관계는 별도 검토 항목이다. 프로젝트 전체에 임의의 단일 공개 라이선스를 추가하지 않았다. 이 기록은 확인 범위 정리이며 법률 의견이나 권리 보증이 아니다.

## BUILD113 공개 자산 재점검 · 2026-11-16

현재 타이틀의 `출처 · 프로젝트 소개`에는 비공식 프로젝트 안내, OSM/ODbL, Mapzen/Skadi/USGS, Babylon.js/earcut 출처와 과거 기록 링크가 들어 있다. 위의 과거 설명처럼 정식 출처 화면 자체가 아직 없는 상태는 아니다. 이번 점검은 실제 사용 파일·제작 기록과 공식 공개 조건의 대조이며, 전 코드 유사성 검사나 법률적 권리 확정을 수행한 것은 아니다.

OSMF 공식 가이드의 게임·시뮬레이션 항목은 크레딧/메뉴 등 적절한 위치에 출처를 둘 수 있다고 설명한다. 따라서 게임 내 왼쪽 아래 출처를 삭제했다는 이유만으로 위반이라고 결론 내리지 않는다. 지도만 따로 배포하거나 사진·홍보영상으로 내보낼 때는 해당 형식의 별도 표시 기준을 적용한다. [OSMF 출처 가이드](https://osmfoundation.org/wiki/Licence/Attribution_Guidelines)

리오 확인 근거: [서울대 공식 2023 봄축제 기사](https://www.snu.ac.kr/snunow/snu_story?bbsidx=141912&md=v). 스누베어 확인 근거: [서울대 공식 생협 소개](https://www.seoul.ac.kr/snunow/snu_story?bbsidx=176312&md=v). 이는 해당 캐릭터의 존재·출처 근거이며 프로젝트 사용 허가가 아니다.

현재 코드·자산과 비공개 서버는 변경하지 않았다. 공개 전에는 위 미확인 항목의 사용 범위를 정리해야 하며, 비공식 안내문이나 출처 표시만으로 허가가 대체됐다고 표시하지 않는다.


### 같은 날 공개 경로 추가 확인 · 2026-11-16

SMASH 원격 LICENSE를 GitHub 연결로 직접 재확인했다(Blob `8d496a620102d67a999f50f732c371251b3f9846`): 건물·도로 데이터에 ODbL 예외가 명시되어 있다. [국토부 GIS건물통합정보 SHP](https://www.data.go.kr/data/15083092/fileData.do)는 공공누리 제1유형, 같은 계열 [건물 API](https://www.data.go.kr/data/15123970/openapi.do)와 [연속지적도 API](https://www.data.go.kr/data/15056910/openapi.do)는 이용허락범위 제한 없음으로 확인했다. VWorld 전부가 출처 불명·이용 금지라는 뜻이 아니다.

다만 [VWorld 이용약관](https://www.vworld.kr/v4po_prcint_a001.do) 제19조는 일반 API 정보 저장·제공 제한과 개별 라이선스 다운로드 예외를 구별한다. upstream의 실제 API 수집조건까지 자동으로 해결됐다고 단정하지 않는다. 공개 근거를 더 직접적으로 연결하려면 공공누리1 다운로드 원본 확보·현재 건물과 대조를 권장한다. 항공영상 파생 대표색은 별도로 현재221개 roof 필드가 upstream과 동일하며, 필요시 독립 색상으로만 바꿀 수 있다. 앱 코드·데이터는 변경하지 않았다. 세부 근거·필드·대체 범위는 BUILD113 `RIGHTS-PUBLICATION-REVIEW.md` 추가 조사 참조.


### 사용자 확인에 따른 범위 정정 · 2026-11-16

사용자는 3NU 로고·백학·리오를 기존 서울대 로고/캐릭터를 참고하여 만들었다고 확인했으며, 현재 외형을 유지해 공개하기를 원한다. 이 확인은 제작 참고 경위를 보강하지만 원권리자의 개별 이용허락을 입증하지는 않는다. 참고 자체가 언제나 사전허가 대상이라는 결론도 내리지 않는다. 보호되는 구체 표현의 유사성·변형 정도, 로고의 출처 혼동 가능성, 공식 상징 사용 규정의 적용 범위가 현재 디자인 유지 조건에서 남는 검토 사항이다. 해당 자산의 독립 창작 또는 허가 취득을 확인완료로 표시하지 않는다. 비상업·비공식 안내는 프로젝트 성격을 설명하는 문구이며 허가를 대신하지 않는다.

이 문서의 임시 제외·대체안은 이전 검토 단계에서 제시한 선택지일 뿐, 현재 승인된 작업이 아니다. 사용자의 추가 지시 없이 로고·플레이어·스누베어 등 외형을 제거하거나 대체하지 않는다. 지도 데이터의 출처/라이선스 확인 작업은 계속 별도로 구분한다.
