# 관리자 접속 기록 — BUILD123 유지보수 패치

공개 버전은 v1.0.4, 내부 빌드는 123으로 유지한다. 게시판 공지·업데이트 내역은 변경하지 않는다.

관리자 로그인 후 **접속 기록**에서 방문 시작 시각, 닉네임, 마지막 활동, 활성 탐험 시간, 입장 여부, 재방문 및 통계 포함 여부를 조회한다. 날짜는 KST 방문 시작일 기준이며 양 끝 날짜를 포함한다. 전체 기간 버튼을 누르거나 날짜를 비우면 보관 중인 전체 기록을 조회한다. 전체 기간 버튼은 통계 제외 기록 포함 설정을 유지한다. 최신 방문부터 50개씩 더 보기로 제공한다. 기본적으로 통계 제외 방문은 숨기며 체크박스로 포함할 수 있다.

기존 이름 없는 방문은 `-`다. 새 클라이언트는 게임 입장·heartbeat에 검증된 표시 이름을 전달한다. 서버는 게임과 동일한 16자·한글/영문/숫자 규칙을 검사하고 해당 방문의 마지막 유효 이름을 보관한다. 타이틀 입력 중인 이름, IP, 경로, 쿠키 원문은 추가 수집하지 않는다. 닉네임은 신원 인증이 아니며 여러 탭에서 이름이 다르면 마지막으로 전달된 이름이 표시된다. 이미 열린 구버전 탭은 새로고침 전까지 이름이 없을 수 있다. 브라우저에 닉네임을 재저장하지 않는다.

DB에는 `visit_names123` 보조 테이블만 추가한다. 방문 행을 수정하거나 과거 방명록 이름을 역으로 연결하지 않는다. 기존 schema 2와 호환되고 기존 서버 코드로 다시 열 수 있다. 방문 삭제 시 이름도 FK cascade로 삭제된다. 기존 보관 정책은 변경하지 않는다. 이 추가 테이블도 기존 SQLite 백업에 포함된다.

`GET /api/admin/visits`는 기존 관리자 인증 뒤에서만 실행되고 no-store 응답을 반환한다. 원본 브라우저 식별값과 토큰은 반환하지 않는다. 표시에는 textContent를 사용한다. 활성 시간은 기존 집계와 동일한 heartbeat lease를 읽어 계산하며 마지막 활동은 정확한 종료 시각이 아니다.

검증: 접속 기록/커뮤니티/게이트웨이 12개 로컬 테스트, 임시 DB Chrome UI 로그인·기존 이름 없음·새 이름·55행 페이지 이동·빈 날짜 결과·기존 통계·로그아웃 확인. 배포의 전체 회귀 테스트와 운영 검증 결과는 `03-history/server-releases/BUILD123-admin-log-20261117-r2`에 저장한다. 운영 사용자 목록이나 자격 자료는 Git에 저장하지 않는다.

정적 자산 검사표의 3개 입력(admin107.js, community107.js, app.js) 해시를 갱신했다. 기존 배포본 대비 모든 구운 건물/지형 파일의 바이트 동일성을 확인했고 app.js 변경은 enter(profile.nickname) 한 곳이다. 기하 생성·렌더링은 변경하지 않아 재베이크하지 않았다.
